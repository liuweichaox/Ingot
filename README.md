## Ingot 是什么

制造现场的数据通常分散在设备、仪器、生产系统、检测系统和工程师的表格中。Ingot 以生产周期为主线，把这些记录连接成可以查询、比较和追溯的生产履历。

工程师可以从一批产品、一个异常工件或一句日常问题开始，查看对应的设备、配方、工装、工艺阶段、过程参数和检测结果。分析中的指标与图表可以继续打开相关生产记录。

## 核心能力

| 能力 | 带来的结果 |
|---|---|
| 现场数据采集 | 持续汇集设备参数、状态变化与检测数据，并保留生产上下文 |
| 生产履历 | 将同一次加工的过程与结果按批次、工件和生产周期关联 |
| 工艺配置 | 维护配方版本、工艺阶段、参数单位、工装和质量方案 |
| 周期与批次分析 | 比较同类周期，定位批次、设备、阶段和参数之间的差异 |
| Ingot Chat | 用日常语言发起工艺调查，获得摘要、指标、图表和相关记录 |
| 分析方案 | 保存目标指标、比较维度和筛选范围，复用经过确认的调查方法 |

## 典型场景

### 良率为什么变化

比较目标批次与历史基线，查看变化从哪一批开始、集中在哪个工位或工艺阶段，以及哪些过程参数同时发生变化。

### 同一配方下，为什么设备表现不同

按设备比较相同产品和配方下的周期时间、关键参数、检测分布与异常频次。

### 工装和刀具什么时候需要维护

沿使用次数或累计时长观察过程特征与质量指标的趋势，为维护窗口提供依据。

### 一个异常工件经历了什么

从检测结果回到对应批次、设备、配方版本、工装和完整过程曲线，并与同批次正常工件对比。

## 产品如何工作

```text
设备、仪器与现场数据
        │
        ▼
 Edge · 采集与现场暂存
        │
        ▼
 Platform · 生产履历与工艺配置
        │
        ├── 批次、周期、工件与检测视图
        ├── 工艺阶段、配方、工装与分析方案
        └── Ingot Chat · 工艺调查与结果下钻
```

一次调查通常经历五步：

1. 汇集设备过程、生产对象和检测结果；
2. 建立配方、工装、阶段和参数的业务含义；
3. 将同一次加工的数据整理为生产履历；
4. 检查数据质量并比较同类生产周期；
5. 从分析摘要回到曲线、检测和生产上下文完成复核。
