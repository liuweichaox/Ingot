# v2.2 已知问题与待办（复审遗留）

本文件记录第二次复审（2026-07-24）识别、但**未在合并前修复**的问题，以及原因。
原则：在没有编译器可验证的环境里，不对无法测试的代码做大范围盲改——那样只会给未验证的代码再叠未验证的改动。以下项等本机 `dotnet build` 绿之后再处理。

## 合并前已修复

- **定级 `comparison_key` 高估**（复审 §2.4.3）：L2"同类可比数"改为按 `comparison_key` 值分组取最大组，键为空时退化为范围内 ready 总数。已在 PostgreSQL 16 上验证（跨双模具场景从错误的 37 修正为正确的 25）。
- **迁移漂移守卫**（复审 §2.1）：新增 `scripts/verify-migration-baseline.sh` 并接入 `verify.sh`。断言每张 Postgres 初始化器建的表都被迁移覆盖，漂移即 CI 失败。

## 待办（需先编译绿，或属较大重构）

| # | 问题 | 复审出处 | 为何未在合并前做 | 建议 |
|---|---|---|---|---|
| 1 | **未编译验证** | §2.3 | 容器无 .NET SDK、代理挡下载、设备 VM 无网络——本环境无法编译 | 本机 `dotnet build Ingot.sln && dotnet test`，报错即修 |
