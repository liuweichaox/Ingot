# 术语表

> 文档状态：**当前事实**。本页统一解释 Ingot 公开文档中反复出现的领域术语；具体数字和成熟度以[当前状态](status.md)为准，产品定位以[品牌规范](brand.md)为准。

## 运行与配方

- **运行**：一次真实生产执行的完整记录，用同一运行身份关联实际条件、过程轨迹、生产上下文和质量结果。
- **配方**：面向特定产品和设备的一组工艺设定，是“下一份配方”建议的载体。
- **配方版本**：引用工艺变量并保存参数设定、修订理由与证据的版本化配置；变量定义和单位来自引用的工艺数据模型。
- **已验证工艺范围**：通过真实运行和质量结果验证过的工艺参数范围；优化建议不得越出该范围和明确的安全边界。
- **过程轨迹**：一次运行中随时间变化的阶段特征，用于定位偏差发生在哪一阶段。

## 证据与准入

- **运行证据**：以同一运行身份关联、可追溯到来源、可独立复核的事实集合。
- **准入**：判断一条真实运行能否进入分析的完整性、可比性和覆盖检查；不通过时停止建议并说明原因。
- **优化观察**：通过质量和覆盖准入的真实配方运行及其质量结果，是可复核的优化样本。
- **可比性**：不同运行在材料、设备、工装、时间和产品等条件下是否足以相互比较。
- **证据缺口**：当前事实不足以支撑结论时明确记录的缺失信息。

## 分析与建议

- **工艺追因**：比较满足可比条件的运行，形成候选原因、反证和证据缺口，而不是单凭历史数据断定根因。
- **下一份配方**：在目标、安全边界和历史覆盖范围内推荐的一份配方，附候选工艺设置、预测区间、风险和选择理由。
- **冻结结果**：建议关联真实运行后，从参数回读和检验事实一次性生成的结果记录，之后不再更新。
- **候选覆盖设计（DOE）**：用于理解变量覆盖与交互的统计设计方法；Ingot 当前只将真实运行及其质量结果纳入产品闭环。
- **响应面**：用可解释函数近似目标与参数关系的代理模型，适合样本有限的场景。
- **贝叶斯优化**：面向单次成本高、可逐次决策的序贯优化方法，前提是变量有限、目标可量化且安全边界明确。
- **代理模型**：以有限样本近似真实过程响应的统计模型，如高斯过程。
- **机理知识**：来自物理、化学或工程原理的可复核知识，用于约束或解释建议，但不替代真实运行证据。
- **Ingot Chat**：有权限限制的核对入口，通过授权只读工具查询结构化事实，并在授权工厂/生产现场内检索已复核工艺资料，回答附带片段级来源引用。

## 部署与职责

- **工厂/生产现场**：现场事件、检验、建议和知识等数据的归属范围，也是 Edge 令牌绑定与相应权限检查的依据。系统内部用 `SiteId` 标识；一个工厂可以有多个 Edge，一个 Edge 只归属一个工厂。当前部署内共享的训练数据集和模型资产另按岗位授权，`SiteId` 不代表所有表均已隔离。
- **Edge 上送令牌**：现场连接器（Edge）上送事件时使用的独立、可轮换凭据，每个工厂独立配置。
- **工程师决定**：建议不会自动发送到设备，工程师负责定义目标与边界，并审核、采用或拒绝每份建议。

## 易混淆的概念

- **计划值与实际值**：配方版本保存计划的参数设定；运行回读保存实际发生的值。实际值缺失时不能用计划值静默替代。
- **安全边界与观察覆盖包络**：前者说明工艺允许范围，后者说明已有运行支持的范围。建议需要同时满足两者，详见[分析与优化](optimization.md)。
- **质量录入与质量复核**：录入保存测量事实；复核由授权岗位按质量方案确认是否可作为正式证据。需要独立复核时，录入人不能替代复核人。
- **建议与版本发布**：采用建议记录工程师决定，不自动发布配方版本。显著变更经修订草稿和发布流程完成。
- **软件验证与现场验收**：自动化检查证明覆盖到的软件契约；恢复、容量、安全和收益必须在部署者环境取得对应证据。
