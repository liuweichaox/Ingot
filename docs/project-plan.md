# 发展规划

> 文档状态：**滚动路线图**。本页描述建设优先级，不把计划写成当前能力。

## 产品方向

> **从工艺数据，到有依据的研发决策。**

Ingot 是开源工艺研发与优化系统。组织配方版本、实验记录与运行证据，支持质量分析、工艺追因和配方优化。

当前已实现的推荐闭环仍以生产运行证据为输入：

```text
站点 + 已发布配方 → 真实生产运行证据 → 下一配方建议
        → 工程师采用 / 修改 / 拒绝及原因
        → 关联实际运行 → 冻结质量结果 → 新一轮观察
```

每条建议冻结站点、配方、质量目标、可调参数与边界，不保存另一套运行计划、审批、执行或结果状态机。工程师始终决定是否采用建议；系统不自动向设备下发配方。

实验参数沿用现有工艺配置：工艺变量定义参数，配方版本保存全部参数设定值；研发工作引用这些配置，不建立平行的变量定义。每次运行本身就是一次实验，实际参数、过程轨迹和质量结果复用运行与质量记录。

现有推荐要求符合准入规则的运行、实际参数和质量结果。工程师在已发布配方版本上登记下一轮校正，或把显著变更做成修订草稿；数据不足时的原因由服务端在生成建议时返回。

## 近期优先级

| 优先级 | 目标 | 完成标志 |
| --- | --- | --- |
| P0 | 运行证据完整性 | 复用配方版本全部参数与质量配置，清晰呈现实际值、来源、缺失项和质量复核状态。 |
| P1 | 推荐准入说明 | 展示运行形成优化观察的依据；不足样本和超界输入有明确拒绝原因，并能追溯到运行和质量记录。 |
| P2 | 决策与结果页面 | 已发布配方版本已接入建议、决定与结果。工程师可把建议采用为下一轮校正，或作为显著变更创建修订草稿，并查看冻结结果。 |
| P3 | 知识复用 | 有来源、范围和冲突检查的知识可解释或约束后续建议。 |
| P4 | 部署韧性 | 本地安装、备份恢复、容量和告警可独立验收；连接器故障不阻断已有运行和质量结果的查询与复核。 |

## 方法与效果边界

响应面、贝叶斯优化、机理融合和其他数值方法都是可替换实现。离线算法评估可以使用冻结的历史数据比较确定性、约束遵守和未来信息隔离；它不形成面向工程师的业务流程，也不替代实际生产结果。

仓库不附带场景效果数据或收益结论。部署者用自己的生产数据评估适用性、质量影响、成本和周期，并决定是否采用建议。

## 长期边界

Ingot 聚焦研发记录、分析和优化，不扩张为生产执行、企业资源、全套质量合规或实验室管理、设备联锁、生产排程、通用数据湖或无人值守控制。未来若增加设备动作，必须作为单独的安全工程项目，受设备联锁、权限、停止和恢复策略约束；它不能改变由工程师确认的建议闭环。
