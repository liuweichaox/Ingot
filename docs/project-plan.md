# 发展规划

> 文档状态：**滚动路线图**。本页描述建设优先级，不把计划写成当前能力。

## 产品方向

> **从真实运行证据，到下一份配方。**

Ingot 是开源工艺追因与优化系统。把每次真实配方运行变成优化证据，在安全边界和历史覆盖范围内持续推荐下一份配方。

Ingot 的正式闭环只有一条：

```text
研发项目 → 真实生产运行证据 → 下一配方建议
        → 工程师采用 / 修改 / 拒绝及原因
        → 关联实际运行 → 冻结质量结果 → 新一轮观察
```

项目保存目标、范围、假设、证据和知识，不保存另一套运行计划、审批、执行或结果状态机。工程师始终决定是否采用建议；系统不自动向设备下发配方。

## 近期优先级

| 优先级 | 目标 | 完成标志 |
| --- | --- | --- |
| P0 | 可信运行事实 | 身份、单位、来源、实际值和质量复核可追溯。 |
| P1 | 决策闭环 | 每条建议都能记录采用、修改或拒绝、原因及实际运行关联。 |
| P2 | 结果闭环 | 参数回读与检验结果齐备后，结果可从源数据一次性冻结。 |
| P3 | 知识复用 | 有来源、范围和冲突检查的知识可解释或约束后续建议。 |
| P4 | 生产韧性 | 站点隔离、备份恢复、容量和告警达到部署方要求。 |

## 方法与效果边界

响应面、贝叶斯优化、机理融合和其他数值方法都是可替换实现。离线算法评估可以使用冻结的历史数据比较确定性、约束遵守和未来信息隔离；它不形成面向工程师的业务流程，也不替代实际生产结果。

仓库不附带场景效果数据或收益结论。部署者用自己的生产数据评估适用性、质量影响、成本和周期，并决定是否采用建议。

## 长期边界

Ingot 不扩张为 MES、SCADA、设备联锁、生产排程、通用数据湖或无人值守控制。未来若接入设备动作，必须是单独的安全工程项目，受设备联锁、权限、停止和恢复策略约束；它不能改变当前由工程师确认的建议闭环。
