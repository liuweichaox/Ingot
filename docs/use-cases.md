# 典型场景

Ingot 围绕制造现场最常见、最需要上下文的问题组织分析。每个场景都从生产履历出发，把结果变化和对应的过程记录放在一起。

## 良率为什么变化

选择目标批次和对比基线后，Ingot 汇总一次通过率、缺陷类型和影响范围，再按工位、工艺阶段、设备或配方比较过程差异。

结果会回答：

- 变化从哪一批开始；
- 差异集中在哪个工位或阶段；
- 哪些过程参数与结果同时发生变化；
- 哪些记录缺失，当前比较覆盖了多少工件。

## 同一配方下，为什么设备表现不同

Ingot 将使用同一配方、相近时间和相同产品的生产周期分组，比较不同设备的节拍、关键参数、检测分布和异常频次。

团队可以由此识别持续偏移的设备、特定时段的变化，以及需要进一步检查的工装或维护记录。

## 工装和刀具什么时候需要维护

生产履历会记录工装、模具或刀具与每次加工的关联。Ingot 可以按使用次数或累计时长展示质量指标和过程特征的变化趋势。

这使团队能够同时看到剩余使用空间、近期劣化速度和受影响的产品范围，为维护窗口提供依据。

## 一个异常工件经历了什么

从工件或检测结果进入，Ingot 会还原关联的批次、设备、配方版本、工装、阶段过程和检测记录。

工程师可以沿时间线查看异常发生前后的状态，并与同批次正常工件或历史相似周期对比。

## 一次工艺调整带来了什么

团队可以为调整前后选择明确的时间窗、产品、设备和评价指标。Ingot 按统一口径展示过程特征、质量结果和数据覆盖率，便于复盘调整效果并保存分析记录。

## 数据是否足够支撑分析

在比较前，Ingot 会检查周期完整性、时间顺序、关键字段、检测覆盖和可比样本。数据质量结果与业务指标同时显示，让工程师知道结论覆盖的范围。
