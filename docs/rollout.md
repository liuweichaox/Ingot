# 落地实施

Ingot 的落地从一个明确的现场问题开始。首个范围越具体，越容易快速验证数据是否完整、分析是否有效，也越容易形成后续扩展模板。

## 第一步：选择首个问题

适合首批落地的问题通常具备以下条件：

- 已经影响良率、返工、节拍或维护成本；
- 有明确的产品、设备、批次或工艺阶段；
- 现场已经保存部分过程和检测数据；
- 工程师目前需要重复导表或人工对比；
- 结果能够由现有记录和现场知识复核。

建议首个问题只覆盖一条产线、一个产品族和一组核心指标。

## 第二步：确认数据清单

围绕首个问题，实施团队与工艺工程师共同确认：

| 数据 | 需要确认的内容 |
|---|---|
| 生产对象 | 产品、工件、批次和生产周期标识 |
| 设备过程 | 设备、工位、时间、阶段和关键参数 |
| 工艺配置 | 配方版本、参数单位和工艺阶段含义 |
| 工装信息 | 工装、模具或刀具标识及使用关系 |
| 质量结果 | 检测项目、结果、单位、时间和工件关联 |
| 对比口径 | 正常基线、目标指标和允许的比较范围 |

## 第三步：连接与校验

Edge 连接现场数据来源，Platform 接收并整理生产记录。实施阶段先使用少量真实周期核对时间、单位、对象关联和阶段划分，再扩大到完整班次或历史批次。

数据校验结果会明确显示周期覆盖、检测覆盖、缺失上下文和时间异常，供现场人员修正映射与配置。

## 第四步：完成首个调查

工艺工程师在批次、周期或 Chat 中发起问题，检查系统选择的范围和对比基线，并对照原始记录复核结果。

首个调查应形成三项交付：

1. 一组可重复导入的现场数据配置；
2. 一套经过确认的分析口径；
3. 一个可以由现场团队复用的调查流程。

## 第五步：扩展范围

首个问题稳定后，再按实际价值扩展更多设备、产品、配方、工装和质量指标。已有的数据映射、工艺阶段和分析方案可以作为同类产线的起点。

## 运行准备

正式使用前，团队需要确定：

- Edge 与 Platform 的部署位置；
- 数据保留、备份与恢复安排；
- 用户、角色和可查看的数据范围；
- 模型服务与访问凭据；
- 日志、指标和告警的负责人；
- 工艺配置与分析方案的维护人。

项目团队可从[常见问题](faq.md)继续了解范围、数据与使用方式。
