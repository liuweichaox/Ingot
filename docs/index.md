# Ingot 文档

Ingot 是面向高成本、小样本制造实验的开源工艺追因与优化系统。它将控制系统、仪器、视觉、检验和业务数据连接为一次真实运行的可追溯证据，用这套证据解释这次运行的偏差来自哪个变量、哪段轨迹，并使用受约束贝叶斯优化推荐下一次运行。

## 六步业务闭环

```text
工艺定义 → 设备接入 → 生产采集 → 数据闭环 → 工艺追因 → 工艺优化
    ↑                                                        ↓
    └──────────── 已验证配方、工艺窗口与知识返回生产 ────────────┘
```

1. **工艺定义**：定义设备、产品、工艺变量、标准单位、配方参数和质量指标；
2. **设备接入**：选择通信驱动，测试真实连接，并把设备点位映射到稳定工艺变量；
3. **生产采集**：依据实际生产开始和结束形成周期，记录过程轨迹、阶段号、实际配方和上下文；
4. **数据闭环**：检查时间、缺失和异常，将检验结果关联到同一生产周期；
5. **工艺追因**：比较合格与不合格运行，形成有数据来源、可控变量和混杂边界的候选原因；
6. **工艺优化**：通过受控实验验证安全候选，把确认有效的参数固化为配方版本、工艺窗口和可复用知识。

追因和优化共用同一条闭环：诊断读的证据就是优化读的证据，区别只在于一个解释已发生的结果，一个决定还没做的实验。采集、检验、特征、实验和知识都服务于这条闭环。Ingot 不要求每个行业建立一套新系统；换场景时，通常只需要替换变量、数据映射、目标、安全边界、特征和可选机理先验。

## 当前状态

当前实现由 Edge ConnectorHost、Platform API 模块化单体、内嵌 Agent、独立 Optimizer 和独立 Web 前端组成，核心闭环已经在代码层完成并具有自动化测试。但真实光学模压历史回放结果尚未公开。项目把“代码可运行”和“已经证明能减少现场实验”明确区分：后者必须通过逐次运行回放和前瞻实验给出证据。

## 公开承诺

- 不把计划设定值冒充实际运行值；
- 不把模型均值冒充确定结论；
- 不让 LLM 生成数值工艺配方；
- 不用模拟数据声称真实工艺收益；
- 每次推荐保留输入快照、模型版本、预测区间和来源哈希。
