# Ingot：AI 工艺研发系统

Ingot 是面向制造业的 AI 工艺研发系统，通过融合实验数据、实时过程数据、物理机理和专家知识，辅助工艺工程师设计实验、发现规律、优化参数并验证工艺窗口，缩短工艺研发周期。

## 解决的核心问题

工艺研发需要应对实验成本高、变量相互影响、样本有限、过程与结果分散、专家经验难以复用等挑战。工程师需要在设备、安全、材料和时间约束下，用尽可能少的实验找到满足目标规格的工艺参数范围。

Ingot 将每个研发项目组织成一条持续迭代的证据链：

1. 定义研发目标、评价指标、变量和约束；
2. 采集实验设备、生产设备和检测仪器的真实数据；
3. 将过程数据、材料、模具、配方和质量结果关联到具体实验；
4. 融合历史数据、物理机理和专家知识形成研发假设；
5. 分析关键变量、工艺阶段、交互关系和不确定性；
6. 设计下一组具有更高信息价值的实验；
7. 根据实验结果更新模型、参数窗口和研发认知；
8. 验证结论并沉淀可追溯、可复用的工艺知识。

## 产品能力

### 自有数据采集

Ingot 通过主流工业协议连接 PLC、控制器、传感器、实验设备和检测仪器，并为具体设备型号和现场点位提供适配。Edge 在现场完成采样、质量判断、断网缓存和恢复补传。

### 工艺研发管理

研发项目统一管理目标、变量、约束、假设、实验、结果、成本、进度和审核，使每次研发活动都具有明确目的和完整上下文。

### 智能实验设计

系统结合已有实验、工艺约束、模型不确定性和信息增益，辅助工程师选择下一组更值得执行的实验，加快工艺空间探索和目标规格收敛。

### 数据与机理融合

系统同时使用时序特征、统计证据、数据模型、物理机理和专家规则，在小样本条件下形成更可靠、可解释的研发判断。

### 工艺窗口验证

候选参数窗口记录适用产品、材料、设备、模具和工况，并通过受控实验确认目标结果、安全约束、稳定性和可复现性。

### 工艺知识沉淀

经过审核的结论保存其证据、适用范围、限制、版本和复验记录，在后续产品、材料和设备研发中持续复用。

## 一条完整研发主线

```text
研发目标
  → 变量与约束
  → 数据与知识
  → 假设与分析
  → 实验设计
  → 现场执行与采集
  → 检测与结果
  → 模型和机理更新
  → 工艺窗口验证
  → 工艺知识
```
