## 当前生产证据流程

```text
工艺配置 → 现场接入 → 生产运行 → 质量管理 → 工艺追因 → 配方优化
    ↑                                                      ↓
    └────────── 建议回到已发布配方版本，由工程师决定下一轮校正 ──────────┘
```

1. **工艺配置**说明系统要认识哪些变量、单位、质量规则和安全边界。
2. **现场接入**可把控制系统、仪器和业务数据转换成统一工艺字段。
3. **生产运行**记录实际条件、阶段、轨迹和生产上下文。
4. **质量管理**唯一关联并独立复核检验结果。
5. **工艺追因**先检查数据是否可靠，再比较运行并找出值得验证的差异。
6. **配方优化**直接汇总真实配方运行，在安全边界和历史覆盖范围内给出下一份配方建议，并记录工程师的采用、修改或拒绝及后续实际运行结果。

这个顺序表达“先有什么，后做什么”。页面菜单可以按岗位习惯排列，但分析仍必须从可信数据开始。

## 当前成熟度

生产运行推荐流程已实现，Web 通过工艺配置管理配方版本参数；每次运行就是一次实验，运行记录和质量结果构成分析及优化的事实输入。配方建议按站点和配方冻结生成条件，工程师决定和后续结果追加记录。完整能力、验证范围与后续建设边界见[当前状态](status.md)和[发展规划](project-plan.md)。

## 阅读状态标签

- **当前操作指南**：可以照着做的步骤。
- **当前事实**：已经实现、已经验证和仍有限制的内容。
- **架构或规范基线**：产品必须长期遵守的边界。
- **分阶段实现或目标设计**：包含未来内容，不能当成当前能力。
- **滚动路线图**：建设顺序会根据验证结果调整。
