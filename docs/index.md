# Ingot 文档

Ingot 是一个面向高成本、小样本制造实验的开源工艺优化系统。它将控制系统、仪器、视觉、检验和业务数据连接为一次真实运行的观察，并使用受约束贝叶斯优化推荐下一次实验。

## 一条主线

```text
定义变量、目标与安全约束
→ 采集实际配方和周期轨迹
→ 关联检验结果
→ 自动形成实验观察
→ 诊断候选变量并提出研发假设
→ 拟合轨迹与质量代理模型
→ 推荐并验证下一炉参数
→ 工程师审核执行
→ 用新结果更新模型
```

采集、检验、特征、实验和知识都服务于这条闭环。Ingot 不要求每个行业建立一套新系统；换场景时，通常只需要替换变量、数据映射、目标、安全边界、特征和可选机理先验。

## 当前状态

当前实现由 Edge ConnectorHost、Platform API 模块化单体、内嵌 Agent、独立 Optimizer 和独立 Web 前端组成，核心闭环已经在代码层完成并具有自动化测试。但真实光学模压历史回放结果尚未公开。项目把“代码可运行”和“已经证明能减少现场实验”明确区分：后者必须通过逐炉回放和前瞻实验给出证据。

## 公开承诺

- 不把计划设定值冒充实际运行值；
- 不把模型均值冒充确定结论；
- 不让 LLM 生成数值工艺配方；
- 不用模拟数据声称真实工艺收益；
- 每次推荐保留输入快照、模型版本、预测区间和来源哈希。
