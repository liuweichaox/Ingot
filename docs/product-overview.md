# 项目概览

Ingot 是面向制造现场的生产数据与工艺分析系统。它把设备过程、生产批次、工件、配方、工装和检测结果组织成连续的生产履历，让工程师能够从一个异常结果回到对应批次、工位、工艺阶段和原始记录。

## 项目价值

制造现场已经有大量数据，但这些数据通常分散在设备、仪器、表格和业务系统中。Ingot 以生产周期为主线建立关联，让过程与结果可以一起查看、比较和分析。

使用 Ingot，团队可以：

- 查看一批产品经历了什么过程；
- 比较相邻批次、同配方设备和同类生产周期；
- 定位良率、尺寸、节拍或缺陷变化出现在哪个环节；
- 将分析结果下钻到原始曲线、检测记录和生产上下文；
- 把资深工程师常用的分析方法沉淀成可重复使用的分析方案。

## 产品组成

### Edge

Edge 靠近生产现场，持续采集设备参数、状态变化和工艺阶段数据。它支持现场常见的数据来源，并在网络恢复后继续补传暂存记录。

### Platform

Platform 保存生产履历和工艺配置，提供设备、工件、批次、周期、检测、配方、工装和分析视图。团队在这里维护分析所需的业务含义，并查看从概览到明细的完整记录。

### Ingot Chat

Ingot Chat 是工艺调查入口。工程师可以用日常语言描述问题，由系统完成数据范围确认、记录检索、周期对齐、指标计算和结果整理。回答中的指标可以继续打开相关生产记录。

## 谁会使用

| 角色 | 主要工作 |
|---|---|
| 工艺工程师 | 比较周期、定位变化、复核参数与质量结果的关系 |
| 质量工程师 | 查看检测分布、缺陷集中位置和相关生产过程 |
| 设备工程师 | 观察设备差异、节拍变化和工装使用趋势 |
| 生产负责人 | 了解批次表现、异常影响范围和调查进展 |
| 工厂 IT 与实施团队 | 接入现场数据、维护部署与访问范围 |

## 从数据到结论

1. 现场数据进入 Edge，并带上设备、工件、批次和生产周期等上下文。
2. Platform 将同一次生产过程中的参数、状态和检测结果整理成生产履历。
3. 工程师从批次、设备、工件或问题进入调查。
4. Ingot 完成数据质量检查、同类周期选择、指标计算和差异对比。
5. 结果以摘要、图表和相关记录呈现，供团队继续核对和处理。
