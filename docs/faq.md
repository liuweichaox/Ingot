# 常见问题

## Ingot 解决什么问题？

Ingot 把设备过程、批次、工件、配方、工装和检测结果组织成生产履历，帮助制造团队调查良率变化、设备差异、工装趋势、异常工件和工艺调整效果。

## Ingot 适合哪些团队？

工艺、质量、设备、生产和工厂 IT 团队可以围绕同一组生产记录协作。不同角色从各自关注的对象进入，并共享同一套批次、周期和指标口径。

## 现场数据怎样进入 Ingot？

Edge 可以连接设备、仪器和现场数据服务，也可以接收批量导入的数据。实施团队为数据补充设备、工件、批次、周期、配方和工艺阶段等上下文，Platform 再将这些记录整理为生产履历。

## 需要准备哪些数据？

首个场景通常需要目标产品和批次、设备与工位、生产周期、关键过程参数、配方版本以及相应检测结果。工装分析还需要工装标识和使用关系。

## Ingot Chat 怎样回答问题？

Chat 先确认目标和时间范围，再检查数据完整性、选择可比较的记录、计算指标并组织结果。回答包含关键数字、图表、数据覆盖说明和相关生产记录。

## 如何查看分析依据？

分析结果保留使用的数据范围、样本数量和相关记录。用户可以从数字或图表打开对应的批次、周期、阶段曲线和检测明细。

## 如何保持不同调查的口径一致？

团队可以维护配方版本、工艺阶段、参数单位、检测定义和分析方案。调查复用这些版本化配置，使不同人员和不同时间的结果能够对照。

## 首次落地需要多大范围？

建议从一条产线、一个产品族和一个已经影响业务的具体问题开始。首轮完成数据清单、现场映射、结果复核和分析方案后，再扩展设备与指标。

## Ingot 怎样部署？

Edge 通常位于现场网络，Platform 运行在工厂或企业的受控环境中。团队根据数据量、网络条件、备份要求和访问范围确定具体部署方式。

## 中英文文档是否保持一致？

公开文档以中英文成对维护，导航和阅读顺序保持一致。
