# Product Language

Ingot serves production, process, quality, equipment, and plant IT teams. The website, README, public documentation, and product interface use manufacturing language and help readers understand the outcomes the project provides.

## Writing rules

- Explain product value before capabilities and workflow.
- Name the work the user completes, such as “review a production history,” “compare production cycles,” or “review an inspection outcome.”
- Name plant objects directly: equipment parameters, inspection outcomes, batches, workpieces, recipes, tooling, and process stages.
- Give each page one clear topic and an explicit next reading step.
- Describe the product through current capabilities and positive actions.
- Present analysis results with scope, sample coverage, and related production records.
- Express data coverage using specific business objects such as missing cycles, stages, parameters, or inspections.
- Keep Chinese and English pages aligned in structure, facts, and tone.

## Preferred terms

| Meaning | Preferred term |
|---|---|
| Product position | Manufacturing production data and process analysis system |
| Stored and connected plant data | Production record, production history |
| One run or operation | Production cycle |
| Analysis entry point | Process investigation, Ingot Chat |
| Data behind an analysis result | Related production records, original records |
| Uploaded photos or files | Inspection attachments, plant photos |
| How data was produced | Recording method, stage source, calculation method |
| An explanation awaiting engineering review | Main difference, possible cause, review result |
| A reusable analysis method | Analysis plan |

## Content scope

The website, README, and public documentation introduce the project, use cases, capabilities, usage, and rollout. Data contracts, code structure, environment variables, endpoint catalogs, and architecture decisions are maintained separately as engineering material in the repository.

## Pre-publication checks

- Can a first-time reader understand Ingot in the first viewport?
- Does the page cover one topic?
- Does it lead with a plant problem and user outcome?
- Can a result lead into related production records?
- Are Chinese and English structure and facts aligned?
- Does navigation take the reader to the next product step rather than implementation detail?
