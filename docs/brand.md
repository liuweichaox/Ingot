# 品牌与标识

Ingot 的名称与标识共享同一个隐喻：**真实周期、检验结果和工艺知识是矿砂，Ingot 把它们熔炼成两样东西——对这次运行的解释，和对下一次运行的建议。**

本文约定 Ingot 的品牌定位、命名资产和标识使用规则。

## 标识释义

标识由三块**锭**的截面（梯形）堆叠而成：

- 两块**钢色底锭**：持续沉淀的过程数据、实验记录和工程知识，是追因的依据；
- 顶部**金锭**：由证据熔炼出的最新结论——偏差归因与下一次运行建议；
- 三块锭之间保持**等距缝隙**：每项记录和结论都有独立来源，可以追溯和复核。

整体轮廓在 16px 下仍可辨认，可用于 favicon、终端徽标与生态图标。

一句话 tagline：

> **Ingot — 看清这次运行，优化下一次运行。** Explain this run, optimize the next.

## 品牌定位

- **产品类别**：开源工艺追因与优化系统 / Open-source Process Diagnosis & Optimization
- **一句话定义**：Ingot 是面向高成本、小样本制造实验的开源工艺追因与优化系统，把真实周期、过程轨迹和检验结果连成可追溯证据，解释这次运行的偏差来源，并推荐下一次运行的参数
- **两个核心问题**：这次运行为什么没达到规格，偏差来自哪个变量、哪段轨迹；下一次运行应该怎样设置，才能用尽可能少的试验达到规格
- **主要用户**：负责新产品、新材料和新工艺开发的工艺、质量、设备和研发工程师
- **产品架构**：研发项目是正式记录主线；Platform 保存业务事实；Optimizer 负责确定性数值计算
- **价值链**：定义目标与约束 → 关联真实周期和检验 → 追因定位偏差来源与候选变量 → 推荐下一步实验 → 工程师审核与执行 → 更新模型
- **系统边界**：Ingot 辅助工程师决策，不绕过安全约束、审批职责或设备控制系统；MES 可以是数据源或集成目标，但不是运行前提

追因与优化是同一套证据的两种用途，对外表达不拆成两个产品：追因给出偏差的解释，优化给出下一步的动作，两者共用真实周期、实际配方、版本化过程特征和检验结果。

对外表达优先说明“缩短工艺研发周期、减少试验次数、保留证据与不确定性”，不使用未经真实项目验证的效果数字。

## 使用规则

- 当前规范资产用于深色背景；新增浅色版本前不要通过滤镜临时改色。
- 最小展示尺寸 16px；四周留白不小于单块锭高度的一半。
- 不改变三块锭的比例、位置关系与配色；不额外添加描边、阴影或倾斜。
- 字标字体为 `Inter` / `Segoe UI` Bold 回退族。
- 产品效果表述必须区分合成演示、历史回放和真实在线实验。
- 品类句和 tagline 以本文为唯一事实源；README、文档站、官网 metadata 出现的定位表述都从这里同步，不各自改写。
- 术语统一：对外核心能力名统一写「工艺追因」和「工艺优化」；「周期诊断」「偏差归因」「下一次运行建议」可以作为具体功能名继续使用，但不用来替代核心能力名。英文对外写 *diagnosis* 和 *optimization*，*root-cause attribution* 只在技术文档中作解释性说明。
