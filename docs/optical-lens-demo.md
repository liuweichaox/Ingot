# 光学镜片 PLC 采集演示

## 目的

这个演示用一个独立的 Modbus TCP PLC 模拟服务，验证“现场连接器 → 平台事件 → 过程样本”的完整链路。数据是可重复的模拟数据，不代表任何真实设备窗口，也不能直接用于生产控制。

## 启动

完整栈已经启动时，在仓库根目录执行：

```powershell
pwsh -NoProfile -File scripts/setup-optical-lens-demo.ps1 -SkipBuild
```

脚本会启动 `optical-lens-plc` 和 `connector-host`，登录平台，并创建或复用以下配置：

- Modbus TCP：`optical-lens-plc:1502`，采集周期 500ms。
- 过程数据模型：19 项，其中 18 项连续过程量和 1 项工艺阶段。
- 配方：20 个控制参数。
- 工装：1 个镜片模具总成、6 个配件。
- 生产上下文：`OL25-420-DEMO-001`，产品为 25mm PMMA 光学镜片。
- 分析方案：绑定同一数据模型，保证过程样本可以进入平台分析链路。

要从头观察一批完整数据，可重启模拟 PLC：

```powershell
docker compose -f docker-compose.app.yml --profile optical-lens-demo restart optical-lens-plc
```

PLC 会先等待 10 秒，然后运行一个 300 秒批次：

1. 预热与抽真空：0–20 秒。
2. 升温：20–95 秒。
3. 恒温保压：95–220 秒。
4. 降温脱模：220–300 秒。

批次结束后服务保持空闲，便于查看连接器的安全停止和重连行为。再次重启即可重新生成一批。

## 验证

健康检查：

```powershell
Invoke-RestMethod http://127.0.0.1:9100/health
Invoke-RestMethod http://127.0.0.1:8001/health
```

平台工作台可从“配置与接入 → 采集配置”查看已发布任务，从“配置与接入 → 现场节点”查看采集器状态；“现场运行 → 生产运行”和“工艺洞察 → 工艺分析”可查看采集到的过程证据。脚本不会输出管理员密码或访问令牌。

## 边界

模拟 PLC 仅用于开发、演示和连接器验收。真实现场接入仍需要由部署者提供设备地址、寄存器字典、单位、量程、时间戳规则和现场安全评审；不能把本演示的参数、工艺窗口或运行结果当作真实光学镜片生产依据。
