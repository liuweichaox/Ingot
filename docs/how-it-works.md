# 系统如何工作

Ingot 以“生产履历”为核心组织数据和分析。生产履历不是一张孤立的数据表，而是一次生产过程中的设备、工件、批次、配方、工装、阶段参数和检测结果之间的关联。

## 1. 采集现场数据

Edge 连接设备、仪器或现场数据服务，采集关键参数、状态变化和检测数据。每条记录在进入中心平台前都会带上时间、来源和生产上下文。

现场可以按实际网络条件选择持续采集、周期快照或批量导入。暂存与补传机制用于保持记录连续。

## 2. 建立生产上下文

Platform 维护分析所需的基础信息，包括：

- 产品与工件；
- 设备与生产单元；
- 配方及版本；
- 工装、模具与刀具；
- 工艺阶段与参数含义；
- 检测项目、单位和质量方案。

这些信息让同一个数值拥有明确的对象、时间、阶段和单位，也让不同批次之间能够按一致口径比较。

## 3. 形成生产履历

同一次加工中的事件、时序参数和检测结果会围绕生产周期关联起来。系统保留原始记录，并生成适合查询的周期、阶段和特征视图。

工程师可以从批次进入周期，也可以从异常检测结果反向找到对应过程。

## 4. 完成工艺调查

调查通常依次完成四件事：

1. 确认目标对象、时间范围和对比基线；
2. 检查数据完整性和样本可比性；
3. 计算指标并比较批次、设备、阶段或参数；
4. 汇总主要差异、覆盖范围和相关生产记录。

Ingot Chat 将这套流程组织成日常语言交互；平台中的周期、批次和分析页面则用于图表查看与逐层下钻。

## 5. 沉淀分析方法

团队可以把常用的工艺阶段、参数特征、比较维度和评价指标保存为版本化配置。后续调查复用同一套口径，使不同人员和不同时间的结果更容易对照。

## 6. 回到原始记录

分析摘要中的指标与图表保留相关生产记录。团队可以查看取数范围、样本数量、曲线、检测结果和对应上下文，继续完成工程判断。
