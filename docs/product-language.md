# 产品用语

Ingot 面向生产、工艺、质量、设备和现场 IT 人员。官网、README、公开文档和产品页面使用制造现场语言，帮助读者理解项目能带来的结果。

## 写作原则

- 先说明项目价值，再说明能力和工作方式。
- 按用户正在完成的工作命名，例如“查看生产履历”“比较生产周期”“复核检测结果”。
- 按现场对象命名数据，例如“设备参数”“检测结果”“批次”“工件”“配方”“工装”和“工艺阶段”。
- 每个页面只承担一个清晰主题，并给出明确的下一步阅读路径。
- 使用正在提供的能力和正向动作描述产品。
- 介绍分析结果时同时说明范围、样本和相关生产记录。
- 数据覆盖说明使用具体业务对象，例如缺少的周期、阶段、参数或检测结果。
- 中英文页面保持相同结构、事实和语气。

## 统一用词

| 含义 | 推荐用词 |
|---|---|
| 项目定位 | 制造生产数据与工艺分析系统 |
| 已保存并建立关联的现场数据 | 生产记录、生产履历 |
| 一次加工或运行 | 生产周期 |
| 分析的入口 | 工艺调查、Ingot Chat |
| 分析结果对应的数据 | 相关生产记录、原始记录 |
| 上传的照片或文件 | 检测附件、现场照片 |
| 数据如何产生 | 记录方式、阶段来源、计算方式 |
| 尚待工程确认的解释 | 主要差异、可能原因、复核结果 |
| 可重复使用的分析方法 | 分析方案 |

## 内容范围

官网、README 和公开文档站介绍项目、场景、能力、使用和落地。接口契约、代码结构、环境变量、端点清单和架构决策属于工程维护资料，在代码仓库中单独维护。

## 发布前检查

- 第一次接触 Ingot 的读者能否在首屏理解项目；
- 页面是否只讲一个主题；
- 是否以现场问题和使用结果为主；
- 是否能从结论继续找到相关生产记录；
- 中英文结构和事实是否一致；
- 导航是否把读者带到下一步，而不是带到工程实现细节。
