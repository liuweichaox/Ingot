# 公开验证开发工作区

本目录中的全部内容都只是**开发与回归证据**。v7 策略是在查看 v3 结果列和保留 episode 之后确定的，因此这里生成的结果都不是外部验证、盲测或协议冻结验证。

## v3 失败诊断

[`v3-failure-diagnosis.ipynb`](v3-failure-diagnosis.ipynb) 校验 v3 保留数据的粒度和摘要计算，再定位两个强基线失败：

- Yacht 的线性响应面在全部 200 个 episode 中都以第一次追加查询达标，已经达到理论最小值；
- Airfoil 的线性、二次、GP 和机理增强模型之间存在有用分歧，因此正确的开发目标是方法准入，而不是一个通吃的优化器。

## v7 候选回归

只有当可见观察中的某个原始控制量同时达到 Pearson 和 Spearman 证据门槛时，候选策略才准入原始线性响应面。其他情况使用原始二次响应面；存在已声明机理特征时，使用“仅机理特征”和“原始控制量与机理特征联合”二次响应面的等权秩集成。结果安全过滤和 GP 不确定性仍包围该决策规则。

运行已披露的回归：

```bash
optimizer/.venv/bin/python \
  tools/public-validation/development/benchmark_candidate.py \
  --episodes 200 \
  --bootstrap-samples 5000 \
  --output /tmp/ingot-v7-development.json
```

这些数字只说明实现已经可以成为冻结候选。它们**不能**替换 v3 保留结果、不能把 v3 的失败结论改成通过，也不能支持公开实验缩减声明。仍需在查看结果前选择新数据，并执行冻结后的后继协议。

## v8 方法路由开发回归

v8 不再因为存在机理特征就直接进入二次模型。单个控制量具有强 Pearson 与 Spearman 证据时仍使用原始线性响应面；没有机理特征时使用原始二次响应面；存在机理特征但观察数尚未超过一阶联合模型系数数目时，以留一误差在原始线性与联合线性响应面之间选择；超过这一最低复杂度门槛后才进入“仅机理 + 联合特征”的二次秩共识。该规则只依赖已经揭示的观察与模型维数，不读取候选结果，也不按数据集名称分支。

以下回归均使用已查看的 v3/v4 数据，因此仍只是开发证据：

- v3 的 400 个 episode 中，v8 相对随机、maximin、线性和二次响应面的降幅分别为 80.75%、29.84%、12.13% 和 18.81%，四项均通过且两个数据集都不更差；相对无机理消融仅为 4.47%，95% CI 为 −3.53% 至 12.34%，未通过。
- v4 的 1,250 个 episode 中，相对随机、maximin和二次响应面的降幅分别为 64.11%、45.97% 和 33.31%，机理消融降幅为 17.36%，四项通过；相对线性响应面总体降幅为 2.84%，95% CI 为 1.43% 至 4.29%，但只有 96% 的评价单元不更差，因此仍未通过逐单元护栏。

这两个未通过项必须和通过项一起保留。它们说明方法路由已修复 v7 的总体线性失配，但尚未证明机理特征在所有数据池都有增益，也尚未证明每个小上下文都不输适用线性基线。v8 只有通过使用全新结果列、重新冻结的后继协议，才可以形成新的公开结论。

## v6 留出结果与 v9 开发边界

v6 在冻结后完成 300 个 LNP3 配方 episode，完整结果保存在 [`../latest-results-v6.json`](../latest-results-v6.json)，并由 [`validate_v6_result.py`](validate_v6_result.py) 独立重算。相对随机与 maximin 分别减少 43.75% 和 35.96%，两项通过；相对线性响应面总体减少 27.61%，但只有 2/3 上下文不劣；相对二次响应面为 −8.46%；机理特征相对无机理版本为 −5.80%，且二者在三个上下文均未做到不劣。因此总体与机理贡献均未证明。

该失败把后继策略的开发问题收窄为“机理特征准入”，而不是继续增加模型复杂度：观察数超过系数门槛并不代表派生特征具有预测增益，后继路由必须用已揭示观察比较原始模型与机理增强模型，并在证据不足时保留原始响应面。v6 的结果已经查看，今后只能用于开发和退化检测；任何新的公开判定必须选择尚未查看结果的新数据并重新冻结。

## v9 保守方法路由开发回归

v9 把容量与留一增益门槛应用到整个代理模型，而不只约束最终排序；样本不足时，机理版和消融版必须生成相同轨迹。强单调证据直接准入线性响应面；其他场景使用线性—二次秩共识，可见观察达到每个原始控制量三条后才融合 GP 达标概率。完整的已披露数据回归结果如下：

| 已披露数据 | 随机 | maximin | 线性 | 二次 | 机理消融 | 仍未通过的护栏 |
|---|---:|---:|---:|---:|---:|---|
| v3，400 episode | +79.64% | +25.78% | +7.05% | +14.10% | 0% | 二次仅 1/2 数据集不劣；消融无增益 |
| v4，1,250 episode | +62.82% | +44.03% | −0.65% | +30.91% | 0% | 线性仅 52%、二次仅 88% 单元不劣；消融无增益 |
| v6，300 episode | +49.97% | +43.05% | +35.62% | +3.54% | 0% | 二次仅 1/3 上下文不劣且 CI 跨零；消融无增益 |

这些数字均是查看结果后的开发证据，不能替换任何冻结结果。它们表明 V9 已执行安全降级，并在三批数据上稳定胜过随机搜索；同时也明确否定“当前版本已经普遍胜过全部响应面”或“机理特征已经证明有用”。下一次判定必须在提交 V9 后先选择未查看结果的新数据，再冻结目标、上下文、样本量和全部门槛。
