# 优化器开发回归

本目录只保留当前开发入口。它读取已经查看过结果的数据，用于定位失败和防止代码退化，不构成新的效果证据。

运行：

```bash
./scripts/benchmark-optimizer-development.sh
```

当前冻结验收已经证明：策略稳定胜过随机和 maximin，并与二次响应面相同；但它在 Alkox 和 P3HT 上分别比线性响应面多用 32.08% 和 68.36% 的追加实验。因此开发目标只有一个：用可见观察可靠地区分线性与二次结构，而不是继续增加模型种类。

任何后继策略都可以使用当前验收数据做开发回归，但不得把重跑结果称为独立验收。新的效果判定必须先提交后继算法，再选择另一批从未查看结果的数据并冻结规则。

过去的内部批次执行器、候选脚本和诊断 notebook 已删除。冻结协议和完整原始结果仍保留在上级目录，作为不可改写的审计记录。
