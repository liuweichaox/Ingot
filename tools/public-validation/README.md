# 公开数据实验效率验证

本目录把“是否减少追加实验次数”固化为可重复运行的配对历史池回放。开发回归与冻结评估使用不同数据和协议，避免把参与调参的数据继续作为外部效果证据。所有结论均限于公开数据中的有限候选池，不外推为任意工厂的收益。

| 证据层 | 用途 | 数据 | 当前状态 |
|---|---|---|---|
| v2 开发回归 | 算法开发、退化检测和声明边界 | FDM、Crossed Barrel 机械设计 | 已运行并保存参考结果 |
| v3 冻结评估 | 强基线比较和机理特征消融 | NASA 翼型噪声、Delft 船模水动力 | 已冻结并保留 400 个 episode 的完整结果；总体声明未证明 |
| v4 冻结评估 | v7 新数据留出 | 建筑能耗仿真、同步电机实验 | 已保留 1,250 个 episode；线性基线与消融护栏未通过 |
| v5 数据质量门禁 | 自动化 HPLC 候选 | Olympus HPLC | 重复设置对账后四个预登记分折小于下限；未运行算法 |
| v6 冻结评估 | v8 新数据留出 | Olympus LNP3 配方实验 | 已保留 300 个 episode；二次基线、线性上下文护栏与机理消融未通过 |

## 数据与场景

基准使用两个许可明确的制造实验数据集：

- FDM 3D 打印数据，DOI `10.17632/zd6td6svd6.2`：162 条完整 DOE 记录，按材料和填充图案形成 6 个独立上下文；层厚、填充率和速度是控制变量，粗糙度和峰值应力是结果。
- Crossed Barrel 增材制造机械设计，DOI `10.1126/sciadv.aaz1708`：600 个结构设计各进行 3 次真实打印与压缩测试，共 1800 次实验；离散空心柱数量形成 4 个上下文，扭转角、外半径和壁厚是控制变量，韧性是结果。

分类因素只作为上下文分层，不会被编码成具有虚假距离关系的连续变量。Crossed Barrel 的同一设计按三次实测韧性取均值，并保留重复次数和样本标准差，避免把重复测量当作多个候选实验。来源、许可、固定源版本、SHA-256 和转换见 [NOTICE](NOTICE.md)，协议见 [protocol-v2.json](protocol-v2.json)。加载器会校验快照哈希、行数、身份唯一性和重复数对账，失败即停止。

## 比较方法

每个回放 episode 都为三种方法共享同一组随机且不重复的初始历史：

1. Ingot 当前生产优化器；
2. 固定种子的无模型随机搜索，用于优效性检验；
3. 正则化线性响应面，用作活性对照和非劣效检验。

如果初始历史已经达标，该 episode 会在运行任何方法前排除。因此指标回答的是：“已有观测尚未达标后，还需多少次追加实验？”所有方法只能查询公开数据中真实存在且尚未观察的设置，不能读取候选结果、插值替换或生成结果。

FDM 使用 4 条初始观测和 12 次总预算，Crossed Barrel 使用 8 条初始观测和 16 次总预算；两者均最多允许 8 次追加实验，预算内失败统一记为 9 次，避免幸存者偏差。每个上下文运行 100 个唯一 episode，共 10 个上下文、1000 个配对回放。Crossed Barrel 的目标是各柱数上下文韧性的经验第 80 百分位，仅是开发回归阈值，不冒充工程规格。

## 判定规则

- 相对随机搜索：追加实验相对降幅的分层 bootstrap 95% 置信区间下界至少为 10%，成功率差下界至少为 -5 个百分点，且至少 80% 上下文不劣。
- 相对线性响应面：追加实验相对降幅的 95% 置信区间下界至少为 -10%，成功率差下界至少为 -5 个百分点，即证明非劣而非宣称优效。
- 数据集护栏：两个数据集分别不得出现超过预设界限的平均退化。

随机搜索代表没有响应模型时的盲试基线；线性响应面本身已经是减少实验的经典方法。因此公开结论必须写成“相对固定随机搜索减少”，不能写成“优于所有 DOE/RSM 方法”。

## 当前参考结果

[latest-results.json](latest-results.json) 是当前完整参考快照：

| 检查 | 结果 |
|---|---|

| Ingot / 随机 / 线性响应面成功率 | 98.20% / 75.90% / 90.40% |
| Ingot / 随机 / 线性响应面截断平均追加实验数 | 2.77 / 4.87 / 3.21 |
| 相对随机搜索降幅 | 43.08%，95% CI 36.19%–49.86%，优效通过；两个数据集护栏均通过 |
| 相对线性响应面降幅 | 总体 13.53%，95% CI -9.41%–27.76%，总体非劣；Crossed Barrel 分项 -33.39%，95% CI -64.45%–-8.38%，护栏未通过 |

该结果来自开发期公开基准，不是事先登记的独立外部验证。相对固定随机搜索的优效结果成立，但数据集护栏优先于合计数字：Crossed Barrel 中 Ingot 的平均追加实验数为 2.13，线性响应面为 1.60，4 个上下文均未做到不劣。因此当前优化器的总体实验缩减声明标记为未证明。该结果也不证明另一个工厂、材料、设备或目标能获得相同收益。

## v3 冻结评估协议

[`protocol-v3.json`](protocol-v3.json) 引入两个未参与 v2 开发的 CC BY 4.0 物理实验数据集：NASA 风洞翼型噪声实验 1,503 条和 Delft 船模水动力实验 308 条。评价器按预先声明的分位数规则生成方法比较目标；该目标用于统一评价，不代表现场工程规格。

每个 episode 共享同一组随机且不重复的初始观察，并比较：

1. 使用预先登记机理派生特征的 Ingot；
2. 不使用机理派生特征的 Ingot 消融组；
3. 固定随机搜索；
4. 序贯 maximin 空间填充；
5. 正则化线性响应面；
6. 正则化二次响应面。

方法只能读取候选参数，只有选中某个设置后才能获得对应结果。主要指标是达到目标所需的截断追加实验数，同时报告预算内达标率。相对全部四个预先登记基线均通过优效规则，才允许形成“相对全部登记基线减少追加实验”的结论；机理特征贡献必须通过与同一优化器无机理特征版本的配对消融，不能由总体优化结果代替。

结果文件同时保留每个数据集的分项统计和实际运行时版本。置信区间在两个固定数据集内按 episode 分层重采样，只描述这些数据集中的 episode 不确定性，不估计跨工艺、跨设备或跨工厂的迁移不确定性。

v3 已按以下流程冻结并完成首次运行：

1. 提交算法、数据快照、转换脚本和协议草案；
2. 运行完整性检查取得 `candidate_evaluation_fingerprint`；在后续仅含冻结元数据的提交中，将前一提交哈希写入 `optimizer_revision` 和 `protocol_revision`，把该指纹写入 `evaluation_fingerprint`，并将状态改为 `frozen`；
3. 此后运行完整评估，不依据结果修改算法、数据、目标、预算、基线或判定阈值；
4. 不利结果照常保留，并把公开结论标记为 `not-demonstrated`。

冻结提交引用候选提交 `70cd12c16df55247dff70971cded312705f4b88b`，统一评估指纹为 `f82d3745530de851a901307f720b127f4db38bc2a1ed4d44d9a0d99fa66bbb5d`。完整结果保存在 [latest-results-v3.json](latest-results-v3.json)：

公开数据的结果列对项目维护者并非客观不可见，因此 v3 是“协议冻结、方法逐次不可见结果”的外部数据评估，不称为独立盲测。独立第三方评估仍是更高等级证据。

## 运行与自动化

完整运行：

```bash
./scripts/benchmark-public-validation.sh
```

默认输出为 `artifacts/public-validation.json`。快速检查可运行：

```bash
uvx --from uv==0.11.32 uv run --project optimizer --locked \
  python tools/public-validation/benchmark_v2.py \
  --episodes 2 --max-scenarios 2 --bootstrap-samples 100
```

- 普通 CI 校验数据快照、协议、声明边界和快速配对回放，不锁定跨平台浮点小数。
- `Performance` 工作流每周或手动运行完整基准并上传结果。
- `latest-results.json` 只在人工审核算法、数据、依赖锁或判定协议变化后更新。

校验 v3 数据、冻结协议和统一指纹：

```bash
./scripts/verify-public-validation-v3.sh
```

完整性检查输出的统一指纹覆盖优化器源码、依赖锁、评估器、规范化协议和两个数据快照；其中任一内容变化，完整评估都会拒绝运行。协议冻结后运行 v3：

```bash
./scripts/benchmark-public-validation-v3.sh
```

|---|---:|---:|---:|---|
| 无机理特征消融 | −5.80% | −16.22% 至 3.58% | 0% | 未通过 |

| 序贯 maximin | 35.96% | 28.64% 至 42.69% | 100% | 通过 |

| 正则化二次响应面 | −8.46% | −20.54% 至 2.42% | 0% | 未通过 |

线性响应面的合计效果为正，但 Stearic acid 上下文中 Ingot 平均需要 1.72 次追加实验，线性响应面为 1.66 次，因而触发预登记的 100% 上下文不劣护栏。无机理消融和二次响应面在三个上下文都不更差；这否定了 v8 在该数据池中自动准入机理二次集成的策略。总体及机理特征贡献均保持 `not-demonstrated`，该结果从现在起只能作为后继方法的开发证据。
